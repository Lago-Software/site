Betriebsrat (CSE)

Der Betriebsrat bekommt seinen Rabatt, Sie behalten den Überblick

Legen Sie einen Betriebsrat in einer Minute an: Lago erzeugt Code, QR-Karte und Vereinbarung. An der Kasse wird der Rabatt automatisch angewendet, und jeden Monat sehen Sie, was er ausmacht.

Kostenlose Demo anfordernKasse ansehen
Kostenlose, unverbindliche DemoTablet, Computer und SmartphoneKasse konform mit französischem Recht

Echter Lago-Screenshot · Demodaten

Ein Code, eine Karte und eine Vereinbarung pro Betriebsrat

Name, Rabatt, Laufzeit und Kontakt eingeben: Lago erstellt einen eindeutigen Code, eine Partnerkarte mit QR-Code zum Drucken und die Vereinbarung als PDF zum Unterschreiben.

  • Eindeutiger Code und QR-Code pro Betriebsrat
  • Partnerkarte zum Drucken, mit Ihrem Logo
  • Vereinbarung als PDF, unterschriftsbereit

Echter Lago-Screenshot · Demodaten

An der Kasse wird der Rabatt automatisch angewendet

Aktive Betriebsräte erscheinen mit einem Tipp auf dem Beleg. Der Mitarbeiter nennt seinen Code oder zeigt seine Karte: Code eintippen oder QR-Code scannen, und der Rabatt wird berechnet.

  • Rabatt in % auf den ganzen Beleg oder eine Kategorie
  • Gültigkeitsdaten, mit einem Klick deaktivierbar
  • Nur ein Partnercode pro Beleg

Echter Lago-Screenshot · Demodaten

Die Übersicht je Betriebsrat und die Monatsabrechnung

Pro Betriebsrat: Belege, eingenommener Betrag und gewährte Rabatte, mit den letzten Belegen. Die monatliche Abrechnung als PDF entsteht mit einem Klick, bereit zum Versand.

  • Belege, Einnahmen und Rabatte je Betriebsrat
  • Monatsabrechnung als PDF
  • Vereinbarung und QR-Code zum Herunterladen

Häufige Fragen

Ihre Fragen

Brauchen die Mitarbeiter des Betriebsrats ein Konto?

+

Nein. Sie zeigen ihre QR-Karte oder nennen ihren Code am Empfang oder an der Kasse: Lago legt für sie kein Konto an.

Lässt sich der Rabatt auf bestimmte Produkte oder einen Zeitraum begrenzen?

+

Ja. Sie wählen den Prozentsatz, die betroffene Produktkategorie und die Laufzeit der Vereinbarung.

Lassen sich mehrere Codes auf einem Beleg kombinieren?

+

Nein, pro Beleg gilt nur ein Partnercode.

Kann der Betriebsrat mit seinem Code online buchen?

+

Derzeit nicht: Der Code wird aktuell am Empfang oder an der Kasse verwendet.

Ist die Betriebsrat-Funktion im Tarif enthalten?

+

Ja, sie ist im Tarif Complet enthalten, ohne Aufpreis pro Betriebsrat oder Beleg.
