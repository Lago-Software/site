À la caisse, la remise s’applique toute seule

Les CSE actifs s’affichent d’un geste sur le ticket. Le salarié donne son code ou présente sa carte : on saisit le code ou on scanne le QR code, et la remise est calculée.

  • Remise en % sur tout le ticket ou sur une catégorie
  • Dates de validité, désactivation en un clic
  • Un seul code partenaire par ticket

Questions fréquentes

Vos questions

Les salariés du CSE ont-ils besoin d’un compte ?

+

Non. Ils présentent leur carte à QR code ou donnent leur code à l’accueil ou en caisse : Lago ne leur crée pas de compte.

Peut-on limiter la remise à certains produits ou à une période ?

+

Oui. Vous choisissez le pourcentage, la catégorie de produits concernée et les dates de la convention.

Peut-on cumuler plusieurs codes sur un même ticket ?

+

Non, un seul code partenaire s’applique par ticket.

Le CSE peut-il réserver en ligne avec son code ?

+

Pas pour l’instant : le code s’utilise aujourd’hui à l’accueil ou en caisse.

La fonction CSE est-elle incluse dans l’offre ?

+

Oui, elle est incluse dans l’offre Complet, sans supplément par CSE ni par ticket.
